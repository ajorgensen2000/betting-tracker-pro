# Betting Tracker Pro v2

## Test lokalt
1. Åbn Terminal.
2. Gå ind i denne mappe.
3. Kør: python3 -m http.server 8080
4. Åbn http://localhost:8080

## Vigtigt ved opgradering
Version 2 forsøger automatisk at hente bets fra den tidligere lokale version.

## iPhone
Når appen er lagt online:
Safari → Del → Føj til hjemmeskærm.

Data gemmes lokalt på hver enhed. Brug Eksportér backup før du skifter enhed.
